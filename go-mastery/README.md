# Learning path

Follow [the study plan](../STUDY_PLAN.md) in order. Each lesson directory contains a brief and space for the Go programs and notes you write. The teacher provides explanations, exercises, hints, and reviews; the learner writes the solutions.

1. [Data and design](01-data-and-design/README.md): collections, structs, errors, files, packages, and tests.
2. [Building programs](02-building-programs/README.md): interfaces, HTTP, context, and concurrency.
3. [Deep Go](03-deep-go/README.md): revisit the earlier advanced examples and study internals.

Begin at [Lesson 01: Arrays, slices, and maps](01-data-and-design/01-arrays-slices-maps/README.md).
